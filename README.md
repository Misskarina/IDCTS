
# IDCTS – Indian Digital Catering and Traveling Services 🚆

A **digital railway reservation system** built to simplify and digitize train seat bookings in India. IDCTS aims to reduce queues, minimize manual errors, and support a broad user base—including those without smartphones—through a hybrid digital + offline access model.

## 🌐 Project Overview

IDCTS provides a **mobile-first web platform** for train reservation that supports:
- Easy booking
- Flexible seat selection
- Admin-controlled offline access
- Efficient management via an Admin Dashboard

## 📌 Features

✅ **Mobile-Based Booking**  
Users can easily search for trains and book seats via a responsive web interface.

✅ **Flexible Seat Selection**  
Choose available seats in real-time with visual seat layout support.

✅ **Offline Booking Support**  
Non-smartphone users can book tickets via admin support, allowing access in rural or offline areas.

✅ **Admin Dashboard**  
Admins can:
- Add/manage trains
- Monitor bookings
- Handle offline/reserved entries
- View user data and analytics

✅ **Real-Time Updates**  
Bookings are instantly reflected in the system with proper validations.
